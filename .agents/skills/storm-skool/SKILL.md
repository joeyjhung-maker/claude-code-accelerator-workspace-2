# /storm-skool — pull wide from growth doctrine, save everything, brief the best (later)

Same discipline as /storm: you don't invent a Skool post in a vacuum, and you
don't write copy here. You raid live growth sources — mentor calls, the
group's own real activity, doctrine already banked in this workspace — and
diversity falls out. The output is **seeds**, nothing more.

**A seed = a mechanic/room/tap tag + a one-line idea. NOTHING ELSE.** The
moment you start writing the post inside a seed, you've jumped the gun. This
skill is not /produce-skool.

Don't confuse this with /storm. /storm fills a seed bank for Facebook/Meta
ads — Concepts, Angles, hooks, awareness levels. This skill fills a seed bank
for posts inside a Skool group, where the job is recruiting members, keeping
them engaged, or nudging free members toward paid — a different game with
different doors.

## The run

### 1. Client, project, room map
Load `clients/{name}/{project}/project.md` if this is project-scoped (e.g.
`b2b-leads-lab`), else `clients/{name}/client.md`. Read it for:
- **The room map** — which Skool groups exist for this client (e.g. AAA
  Ninjas, ROYA, MDAD, B2B Leads Lab) and what each one's job is in the funnel.
- **Locked avatar/framing rules per room** — project files sometimes carry a
  hard rule about what NOT to say in a specific room (e.g. B2B Leads Lab's
  "no escape-9-5 framing" note, which is fine in AAA Ninjas but wrong here).
  Carry these forward as constraints on every seed for that room, not just a
  fact to mention once.
- **Any open cross-seeding tension** — if the project file flags a live
  concern about one room's growth cannibalizing another (e.g. daily B2B Leads
  Lab plugs starving the AAA→paid funnel), that tension applies to every seed
  aimed at the crowded room. Don't resolve it — flag it per relevant seed.

Ask which mode (or read it from what Joey says):
- **Pointed** — "I need 5 handraiser ideas for B2B Leads Lab this week," or a
  specific room/mechanic/job needs filling. Sources get aimed at that order.
- **Open** — fishing for the next big push. Walk more doors, wider net.

**The inventory is the clock.** Ask roughly how many seeds he wants before
calling it (default: 15–25). No plan → default and say so.

### 2. Walk the doors
Never say a source is "blocked." Push every source 2–3 passes — the first
pass is always the boring one.

- **Mechanics door** — the named growth-mechanic list already banked from
  Dan's team (NAPs, Polls, Auctions, Taps, Handraisers, 2-Steps). For each
  mechanic considered, tie the idea to something REAL and current — an actual
  campaign update, a real member result, a real number from the project file
  — never invent a scenario to hang the mechanic on.
- **Mentor doctrine door** — `mentors/travis-sago/hopper-millions/synthesis.md`
  and `digests/05-group-mechanics.md`. Pull the T1/T2/T3 tap sequence, the CAP
  structure, the domino/self-proof mechanic, the crock-pot/microwave
  structure, the 5 Ps. Read the synthesis's "Where this matches, extends, or
  conflicts with B2B Leads Lab" section if the project is B2B Leads Lab — it's
  already done half this work.
- **NHB six-keys door** — `~/Documents/Second Brain/marketing/wiki/organic-content-structure.md`.
  Why/What/How/When/Who/Where as a generator. Check which keys the room's
  recent posts have been leaning on (ask Joey, or read what's in `copy/` for
  that room) and propose seeds for the keys that are thin.
- **UGC/proof door** — mine real, current member/team activity (actual sends,
  replies, closes from whoever's running fulfilment — check the project file
  for who that is) for domino-assignment seeds: a specific small task to
  assign, not a hope that someone posts organically.
- **Competitor-structure door** — named competitor/mentor Skool groups
  referenced in the project file or mentor folder (e.g. Travis's own group).
  Steal post SEQUENCING and structure, never language — mark the seed
  `[source: competitor-structure]` so /brief-skool knows not to Mad-Lib it.
- **Internal vectors door** — what's already worked in this client's own
  Skool post history. Read `copy/` for past Skool posts and the client's
  `skool-headlines-bank.md` if one exists. Pattern-read for what to repeat,
  not what to copy verbatim.

### Check the cadence before deciding the mix
Read `clients/{name}/{project}/skool-cta-cadence.md` if it exists. Taylor
Welch's 75/25 rule ([[taylor-welch synthesis]],
`mentors/taylor-welch/synthesis.md`) targets roughly 1 asking post for every
3-4 pure-value posts, per room. If a room's recent log is ask-heavy, weight
this storm run toward `job: engage` seeds with NO ask attached for that room
— say so plainly when you do ("B2B Leads Lab's last 3 logged posts all
carried an ask — weighting this run toward pure-value seeds for that room").
Don't silently fix the ratio by refusing to generate recruit/ascend seeds —
generate them anyway if the doors surface good ones, just flag the tension
same as any cross-seed caution.

### CTA type — a seed tag, not a mechanic
When a seed carries an ask (`job: recruit` or `job: ascend`), tag which of
Taylor Welch's four CTA types it is, alongside the growth Mechanic tag (the
two are independent — Mechanic is the content shape, CTA type is the ask
shape):
- `comment` — value post, ask lands in the last paragraph, re-pitched in
  the first comment.
- `off-the-heels` — an implicit ask; you mention something in passing and
  the room asks YOU how to get it.
- `direct-promo` — a plain "grab it now" post, no teaching attached.
- `two-step` — "comment KEYWORD and we'll send it." Real swipe reference
  (structure only, never language/numbers) at
  `mentors/taylor-welch/swipes/2-step-master-list.md`.
A `job: engage` seed with a soft handraiser and no offer attached doesn't
need a CTA type — tag it `engagement-only` or leave the tag off.

### The one-mechanic, many-rooms move
Same multiplication logic as /storm's saffron move: don't hunt a new
mechanic for every seed. Take ONE proven mechanic — say, the domino
assignment ("send one letter this week, report back") — and run it across
every room/segment it could fit (B2B Leads Lab as the direct ask, AAA Ninjas
as a teaser pointing at it, ROYA as a deeper tactical version). Each pass
drops a fresh seed, tagged with the same mechanic, different room and job.

### 3. Save the seeds
Every seed, regardless of door, lands in
`clients/{name}/{project}/skool-seeds/YYYY-MM-DD.md` (or
`clients/{name}/skool-seeds/YYYY-MM-DD.md` if there's no project layer):

```
## SK3 [mechanic: handraiser] [room: b2b-leads-lab] [tap: T1] [job: recruit]
Idea: one line.
Source: <where this came from — mentor doc / project.md fact / real event>
```

Required tags on every seed:
- `[mechanic: ...]` — NAP / Poll / Auction / Tap / Handraiser / 2-Step /
  domino-assignment / proof-post / philosophy-stance.
- `[room: ...]` — which Skool group this is aimed at.
- `[tap: T1|T2|T3]` — hook/awareness, qualify, or offer/invite, from the
  Hopper Millions vocabulary.
- `[job: recruit|engage|ascend]` — grow membership, deepen engagement inside
  the room, or push free→paid.

Optional tags when they apply:
- `[caution: cross-seed]` — this seed touches the flagged cross-seeding
  tension for this client (carry the concern, don't resolve it).
- `[cta: comment|off-the-heels|direct-promo|two-step|engagement-only]` —
  required on every `job: recruit` or `job: ascend` seed (it carries an ask
  by definition); optional on `job: engage` seeds.

Numbered so Joey can pick by number in /brief-skool.

### 4. Present + hand off
Show **ALL seeds in one flat list** — every one, copy-paste-able, no
indents, no "best five." Joey's eye does the filtering.

If a door surfaced a real structural gap (a room with no T3 seeds at all, a
mechanic never tried), name it plainly rather than quietly filling it with an
invented seed.

Close: "Skool seed bank has N. Pick numbers when you're ready to brief —
that's /brief-skool." Do not start briefing in this run.

## Rules that bite here
- Seeds stay small. Mechanic + room + tap + job + one line. No copy.
- Full lists, all at once. Never sample.
- Never invent a growth mechanic, a member result, or a proof number. If a
  door needs real material that hasn't surfaced yet, say what's missing and
  move to the next door.
- Carry every room's locked avatar/framing rule from the project file onto
  every seed for that room — don't let AAA Ninjas escape-9-5 language leak
  into a B2B Leads Lab seed, or vice versa.
- A flagged cross-seeding tension travels with the seed to /brief-skool. Never
  silently resolve it by just not picking a room.
