# Editing Rules — the voice, the steer-prompts, the finish

How to push an ad until it's right and clean it to a human voice. Used by `bots/editing-bot.md`.
(Full system context: `../00-full-system-reference.md` Part 6.)

## The steer-prompts (drop-in directions / buttons)
- **Natural language / anti-AI** — too AI → natural; too staccato → natural; short sentences → natural.
- **More bounce** — conversational, musical flow.
- **Shorten (to a word target)** — read through and **cut specific lines**; do NOT compress sentences
  into "little turds."
- **Cut** — be anal; remove fluff lines that don't move the argument forward.
- **Simplify (reading level)** — swap high-falutin Latin words for concrete, earthy Germanic-rooted
  words; ~8th grade → 3–5th grade. *Not* dumber, *not* less intense — just brute-simple.
- **Make better** — "weave" in (don't bolt on) proof / logic / insight; concrete visual language;
  intensify pain or benefit so they *feel* it.
- **Fix transitions** — add "and / because / so" connective tissue.
- **Fix logic** — does this make sense; stress-test specific ideas.
- **CTA** — explicit (formula below) + clear characterizations.
- **Find & replace (semantic)** — e.g. "20 seconds" → "30 seconds" across all ads.

## Core sentence rules
- **One sentence per line. One idea per line.** Each line stands alone; break separate ideas apart
  (keep as one line only if tightly connected and flowing).
- **No staccato fragment phrasing** ("No this. No that." / "Not X — it's Y") as a rhythm trick. Only
  break for rhythm if it genuinely serves the story.
- **Write ACTUAL sentences, not fragments.** If it wouldn't make sense read aloud, fix it ("Empty." →
  "It's empty.").
- **Bounce + natural transitions** — break compound thoughts so each idea breathes, guide between them
  with And / Because / So / But. Reads like someone telling a story, not a list.

## Story structure
- **Tell it linearly.** Open on a specific night / specific moment, unfold in real time. Don't open
  vague or jump around in time.
- **Story FIRST, explanation SECOND** — let the emotional beat land before pulling back to research.
- **Don't cite specific years** — "researchers found" / "a study showed." Keep it timeless.

## Endings & CTA
End on **intrigue** with a fun, relatable characterization of the solution (feels like a discovery,
not a pitch) — "a little 30-second thing I do every morning with my coffee." Then support an explicit
CTA. **Formula:** *[explicit action phrase] + [casual characterization] + [brief benefit tease, 2–4
lines: mechanism/transformation] + [personal proof payoff: first-person, specific, before→after].*

## Anti-AI — avoid
- *Structural:* "statement: then list"; balanced "This isn't X, it's Y"; three-part lists; formal
  transitions (However, Moreover, Indeed, Subsequently, Furthermore, Additionally).
- *Red-flag phrases:* "Not just X, but Y," "Whether X or Y," "This means that…," "Let's
  explore/dive into," "Picture this," "The key/truth is," jargon (leverage, drive results, optimize),
  intensifiers (ultimately, essentially, simply), "One might argue…," "It is worth noting…"
- *AI words:* hurdles, harnessing, unveil, realm, delve, dive in, embark, navigate, tapestry, craft,
  dazzle, evoke, transform, profound, game-changing, insights, synergy, leverage.
- *Embrace instead:* varied paragraph lengths; fragments-as-speech starting And/But/So; conversational
  asides; small imperfections; clear opinions without hedging; pattern interrupts; spontaneous
  questions; big sentence-length variation; specific personal details; conversational flow over
  perfect structure.

## The finish
Re-hook (new hooks ← hook primer + the edited ad) → select → headlines (← headline primer) → select →
format into a clean doc → Creative. Good edits worth reusing → save to `data/saved-edit-rules.md` →
they become new steer-prompts. Feedback you give the bot → fold into the primers as dos/don'ts.
