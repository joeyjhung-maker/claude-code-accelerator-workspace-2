## STORMING — the 8 Ideation sources (external idea engine)
Pulling from the environment auto-generates diversity. The master concept; 8 children:
- **S — Swipes** — competitors: direct / adjacent / cousin. Needs a swipe bank.
- **T — Templates** — reusable structures (mad-lib a winner).
- **O — Organic** — IG / YouTube / follows.
- **R — Research** — forums, competitor comments, your own ad comments ("spy wheel").
- **M — Matrix** — the strategy matrix → creative-diversity gaps.
- **I — Internal Vectors** — your past winners → hypotheses.
- **N — New Styles** — adapt to what's emerging in the environment.
- **G — Gambits** — raw ideas, the catch-all (fed by hypotheses + comments → the flywheel).
Output: STORMING + internal map + instinct → ideation engine → seeds → seed bank → briefs → Copy.
