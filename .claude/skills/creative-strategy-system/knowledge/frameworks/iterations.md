# Iterations — CASHED (variations · scaling on winners)

Three tracks for a winner: **Net-new** (new core idea — the priority), **Variations** (freeze the
winner, turn ONE knob), **Scaling** (amplify, change nothing). (Full depth: `../00-full-system-reference.md`
Part 8.)

## CASHED — the knobs (turn exactly one)
- **C — Concept/Claim** — what you assert (idea + facts, proof, mechanism)
- **A — Angle** — the psychological frame you wrap the claim in
- **S — Style** — visual style / medium / who delivers it
- **H — Hook** — the opening
- **E — Edit** — tone & format dials (length, valence/intensity, register, pacing, CTA)
- **D — Demographic/Who** — the whole segment (biggest swing — borders net-new)

**Decision test — "smallest box that changed?"** Big→small, stop at first yes: new WHO → D · claim/
mechanism changed → C · same claim new FRAME → A · same claim+frame new LOOK/presenter → S · same
everything new OPENING → H · only tone/length/pacing → E.

## IDENTIFY first — decode the winner before turning a knob
Desire → D · Avatar → D · Awareness → D · Problem/Positioning → C · Mechanism → C · Authority/Proof →
C · Emotion → E · Frame → A. Read off what it's set to, then change only one thing.

## The high-priority moves (🔴)
- **Re-Aim (D):** awareness-level recut · mechanism-segment swap.
- **Re-Concept (C):** mechanism re-explain · proof/credibility swap · overcome objections (from
  comments, woven) · extended problem section.
- **Re-Angle (A):** reframe the claim · negative framing ("honestly, don't buy this…").
- **Re-Skin (S):** swap who delivers · VO ↔ text-on-screen · organic/ugly edit · port format
  (video↔static, static extraction, native static, static + congruent LP) · VSL expansion · **change
  setting**. For video, **use CAST** (Conceit · Actor · Style · Terrain) to pick the knob — push
  Conceit/Style for novelty, swap Actor/Terrain to scale.

## Visual list — every creative type (the Re-Skin source)
- **static · native** (unaware/problem) — built via **SCRAWLS** (`scrawls-statics.md`).
- **static · templated** (solution/product) — man-holding-sign · writing-on-body · meme · text-overlay ·
  chat-screenshot · review-screenshot · comparison-chart (per-format bots).
- **static · branded** (product/most) — hero product · offer/promo · packaging · before/after.
- **video · human-led** — UGC · talking-head · whiteboard · green-screen · podcast/interview · street
  interview · founder/authority (Actor is the swappable knob).
- **video · animation-led** — Pixar/3D · claymation · motion-graphics.
- **video · presenter-less** — VO + b-roll · text-on-screen only · product demo / screen-recording.
- **Re-Hook (H):** volume hook-swap (proven body + 5–10 openings) · winning-hook remake · comment-reply
  hook.

## Scaling (change nothing)
Budget ladder ($100→200→350→550→750→1,000, don't wait) · creative-volume flood (10–20 diverse
creatives) · stack-winners mega-ad.

## The split (adjustable)
Budget ≈ 70 scale / 20 iterate / 10 net-new. Production effort rides account maturity: cold ≈ 85%
net-new → mature ≈ 25–30% (never zero — winners fatigue). Real driver is the matrix: big gaps → bias
net-new · well-covered + fresh winners → bias iterate.
