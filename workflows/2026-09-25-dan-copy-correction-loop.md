# Dan copy correction loop

Related: [[Promotion]] [[Memory Loop]] [[dan-skool-chatgpt-rubric]]

Run this every time Joey returns an edited Dan/Flexxable draft. The objective is not merely to replace the copy; it is to make the next first draft require fewer corrections.

## The loop

1. Save Joey’s version verbatim as the new source of truth. Preserve intentional formatting, rough grammar, slang, capitalization and punctuation.
2. Diff it against the exact version Joey received, not against an earlier Mariobot draft.
3. Identify only consequential changes in hook, rhythm, scene, mechanism, personality, payoff or CTA. Do not manufacture a lesson from routine typo fixes.
4. Add the final piece to the Dan judge’s specimen list when it demonstrates a genuinely new repeatable pattern.
5. Bank repeated or consequential client-specific lessons in `clients/flexxable/voice-and-emphasis.md`.
6. Strengthen `rubrics/dan-skool-chatgpt-rubric.md` only when the correction exposes a reusable judge failure. Keep the rubric lean.
7. If the failure belongs to the production skill rather than Dan’s voice, log it in `skills/observations.md` for later skill maintenance.
8. Confirm what was saved and which lessons were promoted without reprinting the entire post.

## Current hard gates

- Never machine-gun the whole post. After one-sentence-per-line formatting, rewrite any accidental run of three or more tiny sentences unless it is an intentional closing crescendo.
- Plain spoken reactions usually beat writerly aphorisms.
- Do not force playful Dan-isms into serious rally posts.
- Preserve Joey’s final wording exactly; flag factual uncertainty separately rather than silently correcting his copy.
- Use plain text in chat so the copy can be pasted into Google Docs cleanly.
