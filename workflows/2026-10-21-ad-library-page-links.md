# Meta Ad Library links for a list of stores

Related: [[Promotion]] [[2026-10-21-trends-product-sweep]]

## The play
Free, browser only. No WinningHunter credits (about 100 per store).

1. Search the Ad Library for the store's domain:
   `https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=ALL&is_targeted_country=false&media_type=all&q=<domain>&search_type=keyword_unordered`
2. The results page carries each ad's page ID and page name. Tally them and pick the brand-named page that sends ads to the store's domain.
3. Write the page link:
   `https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=ALL&is_targeted_country=false&media_type=all&search_type=page&view_all_page_id=<PAGE_ID>`
4. No brand page found? Write the domain search link and flag the row. Never guess a page ID.

## Watch-outs
- Many brands run several look-alike pages ("Primal Storm" and "PrimallStorm"). Use the one with the most ads, and list the others.
- Some stores advertise through advertorial pages with other names ("Trending In Korea" for Hanae Korea). The biggest advertiser for a domain may not carry the brand name.
- Regional and franchise pages turn up ("Nude Mints Brasil", a local MosquitoNix franchise).
- For TikTok Shop rows (column B is a WinningHunter link), search the store name instead of a domain. It's noisier.
- The tally only sees the first ~30 ads, sorted by impressions, so "most ads" is approximate.
- Hand the bulk work to a Sonnet subagent. It took about 15 minutes for 63 stores.
