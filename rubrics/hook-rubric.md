# Hook Rubric — the Judge's scorecard, hooks only

*The hook is 80% of the game — a bad hook can't be rescued by good body copy. This is
why it gets its OWN judge pass, separate from [[copy-rubric]] (which grades body copy
and headlines). Same two-brain trick: `ad-hook-bot-1` (or whichever bot) drafts hot, this
rubric grades cold, before Joey ever reads a hook.*

**Status: SEED.** Built 2026-08-24 from two sources: the existing "8 vicious-hook
principles" (Luke's training, previously embedded in copy-rubric.md) and Joey's Genesis
"Hook Amplification" training doc (the Four Moves framework). Teaching depth for both
lives in [[hooks]] (`brand/hooks.md`) — this file is the compressed PASS/FAIL scorecard.

Scope: hooks only (the first line/first ~20 words of any ad — text, video, or static).
Related: [[hooks]] [[Promotion]] [[winners]] [[losers]]

---

## How to grade

Score every rule below as PASS / FAIL. Any FAIL → rewrite that hook and re-grade. Only a
clean pass reaches Joey. **Output a rule-by-rule PASS/FAIL scorecard, never a prose
summary** — same standard as copy-rubric.md.

**Provenance rule applies here too.** Grade and auto-fix AI-written hooks hard. A hook
Joey wrote himself gets FLAGGED, never silently corrected.

---

## STEP 0 — Setup (do this BEFORE grading, not as a grading rule)

**Aim it (OSP targeting).** Before touching a single hook, write down: which suspicion
does this market already carry, whose enemy gets the rock, which past failure needs
justifying, which identity is under threat. A hook aimed at nothing stored produces a
loud, dead line no matter how intense the wording — this isn't optional context, it's
the target the rest of the rubric checks against.

**State the idea as one ugly sentence.** Would the market stop for the BORING version?
If not — if the bare idea is a platitude they already believe, or a claim so mild
nobody would repeat it at a bar — the fix is a better idea, not better words. Polish
never rescues a bad idea. (This is the Ineffective Gate below, applied up front.)

---

## GATE 1 — The Core Equation (grade the trio before admiring the craft)

`Attention = Relevance x (Curiosity + Tension + Value + Novelty) x Credibility`

- [ ] **Relevance** — something relevant to THIS reader in the first 10-20 words.
- [ ] **Tension** — a real stake, not just an interesting fact.
- [ ] **Value or Novelty** — a promise, a new mechanism, or genuine surprise.

**FAIL if the core trio is weak and the hook is leaning on amplifiers to compensate** —
a great open loop with no tension underneath is a trivia question, not a hook. Grade
relevance/tension/value FIRST; only then look at craft (specificity, stakes, open loops).

**FAIL — narrowed market check.** Does the hook only speak to people who already own
the category/product ("your turmeric bottle...")? If so it's silently shrunk the
addressable market. A hook that speaks to the SYMPTOM ("your knees...") beats one that
only speaks to existing owners.

---

## GATE 2 — The Ineffective Gate

An idea shaped like "X doesn't work" may NOT enter the hook as-is — nobody feels
betrayed by "ineffective." **FAIL** any hook that states a flat non-performance claim
without escalating it through one of:
- **What's IN it** — the corner-cutting/contamination that's actually happening.
- **What it KEPT you on** — the harmful thing the false relief protected.
- **What it let PROGRESS** — the condition that advanced while you thought you were
  fixing it.
- **What it STOLE outright** — the exact prize the reader paid for, taken from them.

---

## GATE 3 — The Four Moves

Every hook needs all four. Missing even one is the difference between a killer hook and
a dead one — grade each explicitly, don't eyeball it as a whole.

- [ ] **1. THE WORST TRUTH.** Not the loudest claim — the worst TRUE one. If the crime
  reduces to "doesn't work," Gate 2 should already have escalated it. Then set the
  volume with the most charged TRUE framing available (caricature license — "flavored
  SEAWATER," not "mostly sodium"). **FAIL** if a softer/safer framing was chosen when a
  more charged true one existed.
- [ ] **2. THEIR MOMENT.** What specific moment of the reader's own life does this line
  make them SEE — staged (written into the line: "forgetting your keys?") or summoned
  (the line forces them to picture their own shelf/mirror/bottle without describing it:
  "white beard oil")? **FAIL** if the hook stays abstract with no moment attached — a
  claim with no scene is a diagnosis, not a hook.
- [ ] **3. THE FACE.** What is this crime already CALLED, and who's doing it? A coined
  name (fake gold, the leash, seawater) or a caught-in-the-act villain performance
  ("...then acting surprised your cells are SCREAMING"). **FAIL** if the crime is true
  and named but faceless — "the brand picked the cheaper form" is accurate and inert.
- [ ] **4. THE ITCH.** Write down the SPECIFIC question the reader is left holding
  (which word, which brand, is mine one?). **FAIL** if the answer is "none" — a hook
  that explains its own cause completely is a diagnosis. Put the mystery back by
  withholding the discriminator. Then the bar test: could this be said out loud across
  a table exactly as written? If it reads like ad copy, it isn't rendered yet — swap
  soft words for detonators, stop at the hardest one.

**The sentence to hold in your head:** every killer hook is the worst true thing,
landing in a moment they lived, with a face on the crime, leaving one question burning.

## GATE 3B — The Gold Shelf (judge against these, don't copy them)

*Joey's instruction on adding these (2026-08-24): "these are not perfect and we should
be creative enough to come up with different styles... but something to review against."
Use as a structural benchmark — does THIS hook deploy one of these three mechanics, or a
different one that's doing equally load-bearing work? Never mad-lib these verbatim into
a new product; a hook that matches none of the three patterns below can still PASS if it
finds its own structure that hits the Four Moves just as hard.*

**Batch 1 — the trust-token crime (sunscreen).** The thing the reader trusts is the
subject of a crime verb; the trust token sits right beside the crime; the turn happens
on a clock (a same-day before/after); the line stops at the punch, no explaining.
> "The sunscreen that's SUPPOSED to be protecting you... is trapping heat that slow-cooks your skin's collagen."
> "That 'protective' sunscreen is actually TRAPPING heat... MELTING your skin's collagen like a magnifying glass."
> "Your sunscreen is COOKING the collagen out of your face."
> "The wrinkles you blame on birthdays were MANUFACTURED by your SPF."
> "Every morning you rub a little more AGING in your face and call it 'sun protection'."
> "Sunscreen is the only product on your shelf that ages you while you THANK it."
> "That same coat of SPF you smoothed on at 7AM turned against your skin by lunch."
> "Your sunscreen protects your skin at 9AM and starts DESTROYING it by 11."
> "Korean dermatologists use salmon DNA to REBUILD the collagen your trusted sunscreen COOKED."
> "Your SPF 50 is DISSOLVING the collagen that keeps your eyelids from drooping."

**Batch 2 — the coinage that carries the whole indictment (beard oil).** One coined
term does triple duty — names the enemy, names the tribe it's against, hands the reader
absolution in the same breath. Closes on "that's why" landing on the reader's own
symptom, in his own words. Offers a verification the reader can run himself right now
(flip the bottle, check the reviews) — no trust required, he confirms it.
> "Most 'white beard oil' clogs the follicles that actually cause growth for black men."
> "Beard oil made for 'white hair' CHOKES the follicles of black beards. That's why your patches won't go away."
> "I used the same beard oil as my white coworker. His patches filled in. My spots got worse. The same oil growing his hair was STRANGLING my follicles."
> "Flip your beard oil bottle over. Nothing on the label says 4c. That's why the oil nourishes STRAIGHT hair while clogging the follicles of men like us."
> "If all the 'five-star reviews' on your beard oil come from 'white hair', it's likely to strangle the roots of a black beard. That's why you still have patches."
> "Every morning you oil your beard. And every morning, that oil packs the clog CHOKING your growth."

**Batch 3 — the caricature that's still true (turmeric / electrolytes).** The coinage
sits in air quotes (signals "this is my name for it," not a fabricated stat). Volume is
cranked to full caricature while staying factually true underneath. Enters through a
SYMPTOM door, not the product category. The villain gets caught mid-performance, not
just mid-crime — the cover act after the act.
> "Eat this 'white carb' before bed to burn stubborn belly fat overnight."
> "Cardio murders your metabolism... and makes it impossible to lose stubborn fat."
> "At my cousin's wedding, an 82 year old Indian homeless man yanked on my wrist. And fixed the 20 years of back pain my doctors never could."
> "98% of store-bought Turmeric contains 'fake gold' that POISONS your brain instead of fixing your knees."
> "Forgetting your keys? That could be poisoning from the 'fake gold' in the turmeric you bought for your knees."
> "Most electrolyte companies are selling you flavored SEAWATER in fancy packaging. Then acting surprised your cells are SCREAMING with thirst."

**Grading instruction:** don't FAIL a hook just because it doesn't fit one of these
three molds — these are proof of a level, not the only shapes that reach it. DO flag a
hook as under-cooked if, held next to these, it's obviously not swinging as hard —
missing the crime verb, missing the clock, missing the self-verification, missing the
caricature license. Push for a version that would sit comfortably on this shelf, in
whatever structure fits the product.

## GATE 4 — The Loop Gate

- [ ] Does the hook leave a genuine open question, or does it fully resolve itself?
  **FAIL** a hook that discloses its own conclusion ("the brand cut corners because it
  was cheaper" — betrayal confirmed, nothing left to find out). A withheld cause reads
  like a secret; a disclosed one reads like an op-ed.
- [ ] **One curiosity thread, not three.** Three competing open loops dilute — the
  reader can't hold them and picks none. **FAIL** any hook trying to open more than one
  loop at once; pick the single most magnetic question and starve the rest.

---

## GATE 5 — Hook intensity (too polite is a FAIL)

- [ ] **The flinch test.** Read it aloud. If it doesn't make a non-marketer visibly
  react — wince, laugh, say "damn" — it's too tame. **FAIL.**
- [ ] **Escalated first, dialled back second** — was the version that made YOU
  uncomfortable found before pulling back for compliance? A hook written at a
  comfortable 4 when a 5 was available fails even if the 4 "works."
- [ ] **Push to the edge of reality.** Comfortable and plausible = not there yet. The
  reader should think "there's no way..." and need to find out.
- [ ] **Third-person the scary claim where compliance demands it.** "Most guys have no
  idea their liver is 18 months from shutting down" beats "YOUR liver is shutting
  down" — same fear, softer compliance profile. Not a downgrade, a delivery choice.

---

## GATE 6 — The 8 vicious-hook principles (craft depth: [[hooks]])

- [ ] **Relevance in the first line** — pain/condition call-out, belief call-out, or
  pure intrigue, inside the first 10-20 words. Throat-clearing = FAIL.
- [ ] **Protect the charged word** — the detonating word IS the hook ("sexless" not
  "unfulfilling," "killing" not "hurting"). A softened synonym = FAIL, restore it.
- [ ] **Caveman / Germanic language** — five-year-old-simple. A Latinate/clinical word
  where a blunt one exists = FAIL.
- [ ] **Consequence before mechanism** — lead with the wound, not the scalpel. A hook
  opening on HOW before WHY they should care = FAIL, mechanism belongs in body copy.
- [ ] **Reads like information, not an ad** — story, confession, news, or promised
  insight. If it reads like an ad, it's dead on arrival.
- [ ] **Emotionally charged, visceral language** throughout, not just the opener.
- [ ] **Specificity & tangibility** — "300-page report," not "a report." Vague = ad;
  specific = fact.
- [ ] **Natural intrigue / open loop** present (also covered by Gate 4, but check it
  reads naturally, not manufactured).

---

## GATE 7 — Substance gates (run on the bare claim, before craft)

- [ ] **The Product Swap Test.** Strip the hook to its bare claim — could it sell a
  mattress, a coffee, a supplement, and an app equally well? If yes, **FAIL** — find
  the angle only THIS product/mechanism can own.
- [ ] **The Step-Back Bullshit Detector.** Say the bare claim out loud, no adjectives.
  If it's a platitude the reader already believes ("you are what you eat"), **FAIL** —
  no amount of craft rescues a dead idea.

---

## GATE 8 — Client-specific checks (Flexxable)

- [ ] **[[dan-truth-constraint]] tense discipline.** Any Dan-voiced first-person
  burnout/pain content must read as a CLOSED chapter (past, resolved) — never present-
  tense ongoing struggle. His current business model is what gives him the freedom he
  spent years without; a hook implying he's still in it is a FAIL, not a taste call.
- [ ] **Mechanism check.** If the hook (or the body it opens into) touches the
  mechanism, it's OLD/dead-lead reactivation via AI+SMS — never "new lead generation."
  See [[iaa-mechanism-old-leads]].
- [ ] **Never invent a result, number, or quote.** Hooks rarely carry proof (correct
  for Unaware/Problem-aware), but if one does, it must trace to a verified line in the
  client file. FAIL and ask if it doesn't.
