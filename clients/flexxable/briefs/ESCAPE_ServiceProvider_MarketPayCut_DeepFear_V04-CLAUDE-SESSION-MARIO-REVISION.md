- "The client risks nothing" — banned. State the exact fact instead: no setup fee, and the client pays from the sales generated.

## Failure 4 — banned word and banned structures

- "deliverables" is a banned word.
- "Same scope, same expectations, same deadline pressure." is a three-beat fragment stack. Make it one flowing sentence.
- "And it's probably not because your work got worse. / It's because..." is a "not because X, it's Y" stitch. Say it as one plain sentence about what the buyer has seen AI do.
- "There's a different move." is a canned run-up before the claim. Go straight into the pivot.
- Too many ellipses. Use them only on the pivot ladder.
- No emoji.

## Failure 5 — the first line is too polite
