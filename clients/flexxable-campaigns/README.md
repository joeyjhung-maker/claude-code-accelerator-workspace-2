## Per-campaign folder shape
- `brief.md` — the Script for that campaign: core theme, offer frame, structure, open questions.
- `email-tracker.md` — email-by-email status across the funnel parts.
- `testimonial-bank.md` — structured proof, indexed by angle (from images + docs).
- `winning-structure-6.0.md` — the proven launch skeleton we model on (ROYA 6.0, $1.08m).
- `emails/` — working drafts.
- `source/` — raw source material, verbatim, don't edit (incl. `testimonials/` images).
