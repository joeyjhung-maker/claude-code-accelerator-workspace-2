# Memory Loop

Memory is a loop, not a pile of notes.

Claude reads the workspace, does the work, writes a trace, and then you promote only the lesson worth keeping.

The trace (step 3) happens every session, automatically — it doesn't wait for you to ask. Promotion (step 4) stays a deliberate, occasional call. Conflating the two is how sessions used to go untraced: if nobody ran the promotion step, nothing got written down at all.

## The loop

1. Start from [[The Script]] — Claude also checks the most recent daily note for open threads.
2. Work from real files and examples.
3. Save the actual work in the workbench, and log a short trace to today's daily note.
4. Promote the durable lesson into the right memory folder — only when something repeats or corrects a miss.
5. Start the next session with better context.
