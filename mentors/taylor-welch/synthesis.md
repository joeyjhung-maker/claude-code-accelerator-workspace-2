## The four CTA types

Every post that asks for something falls into one of these. Name the type when planning a post —
don't default to the same one every time.

1. **Comment CTA** — you're teaching/posting real content, and the LAST paragraph pitches,
   ending in "instructions in the comments." The comment itself is a second pitch opportunity —
   post the value, then re-pitch with a direct link/promo inside your own first comment. This is
   the most common shape for a value-post-with-an-ask.
2. **Off-the-Heels CTA** — an implicit ask nobody can see you making. You mention something in
   passing ("next month's training covers X, sorry if you miss it") and members ask YOU (or each
   other) how to get in — you never have to pitch directly. The sneakiest and least "salesy"-
   feeling of the four, but harder to engineer on demand; it works best when there's a real thing
   coming that's genuinely worth mentioning in passing.
3. **Direct Promo CTA** — plain direct-response: "we're publishing X next week, grab it now."
   Taylor uses these sparingly and "only in cadence" — mainly for something people already want
   but forgot about, not for cold introduction of a new offer.
4. **Two-Step CTA** — "comment KEYWORD and we'll send it to you." The classic lead-flood mechanic
   (Taylor claims he pioneered it ~2018). Sophisticated audiences now recognize the pattern, so it
   needs real value/qualifier framing to still work — see the master list for the actual
   qualifier language that makes it land (a short list of conditions the reader has to "agree to"
   before getting the asset, which does double duty as a soft filter AND a scarcity/exclusivity
   signal). This maps directly onto the `2-Step` mechanic already in /storm-skool's taxonomy.

## The 75/25 cadence rule (the 1:4 ratio)

**Every third or fourth post carries an ask. The other two-to-three are pure value — nothing
asked in return.** Taylor states this as a 75/25 split: 75% of posts are value with zero ask,
25% carry a CTA of one of the four types above.

**The rule inside the rule: even the 25% that DO ask must still deliver real value in the same
post.** Never a bare ask. Every example in the master list teaches or reveals something
substantial (a framework, a real number, a genuine insight) BEFORE the ask ever appears — the ask
rides on top of value already given, not instead of it.

**Why this matters for B2B Leads Lab specifically:** Joey flagged after reviewing this that a
recent stretch of posts ran too many asks back-to-back without enough pure-value posts between
them — exactly the failure mode this ratio exists to prevent. The fix isn't "ask less
persuasively," it's "count the asks against the ratio before locking the next one." See
/brief-skool's cadence check and `clients/flexxable/b2b-leads-lab/skool-cta-cadence.md` for the
mechanism that enforces this going forward.

## Engagement-boost mechanic (carrot vs. stick)

If CTAs run too often, engagement visibly drops — Taylor's own stated symptom for when the ratio
has drifted. Two ways to reset it, in ascending order of aggression:

- **Carrot** — give something away in pure exchange for a comment/reaction: *"I love you guys —
  as a way to give back, I'm giving away [X]... 'LOVE YOU' below and it's yours."* Generates
  comments and gets the post favored by the algorithm/feed. Low-risk, matches Dan's warm register.
- **Stick** — a bare interest-check post ("hey we have this thing, who's interested?"), followed
  — if engagement still doesn't recover — by an actual house-cleaning purge of non-responders.
  Taylor runs this literally (an annual "comment to stay or get removed" cleanup). **This is
  aggressive and doesn't obviously fit Dan's voice or a group that's still trying to grow FAST
  before the Sept 30 paid conversion** — flagging that it exists rather than recommending it. If
  B2B Leads Lab's engagement genuinely stalls later, the carrot version is the one to reach for
  first; the stick version is a conscious call for Joey/Dan to make, not a default.

## Flexxable enhancement — the "report back" qualifier (banked 2026-09-02)

Taylor's own qualifier conditions in the master list are almost always a passive
please-don't-waste-it promise ("IMPLEMENT what's inside," "watch it this week"). Joey's edit on
the first B2B Leads Lab Two-Step (the Topa database post) replaced that with an ACTIVE
report-back ask instead: "Let us know the results!" This still filters for genuine intent — same
job as Taylor's version — but it also plants a standing reason for whoever takes the asset to
come back with a real result, which feeds directly into the domino/self-proof mechanic from
[[hopper-millions synthesis]]. **Default a Two-Step's second qualifier toward "report back" over
"promise to use it" whenever the mechanic allows** — it does the filtering AND seeds the next
proof-post, two mechanics from one line. See the full diff at `rubrics/copy-rubric.md`'s
"Two-Step CTA post (2026-09-02)" entry.

## Where this plugs into the pipeline

- **/storm-skool** — when generating seeds with an ask attached, tag which of the four CTA types
  fits, not just the growth mechanic (NAP/Poll/Auction/etc — those describe the CONTENT shape;
  CTA type describes the ASK shape, and the two are independent choices).
- **/brief-skool** — the CTA type field, and the cadence check against
  `skool-cta-cadence.md` before locking any brief with `job: recruit` or `job: ascend` (both of
  which carry an ask by definition).
- **/produce-skool** — logs every shipped post's room/date/has_ask/CTA-type to
  `skool-cta-cadence.md` at the Save+flip step, so the next brief's cadence check has real data.
