# obsidian-markdown

No command — it loads whenever Claude is writing notes into the vault.

Use it when you want notes that use Obsidian properly, not just `[[wikilinks]]`.

It covers callouts (`> [!warning]` boxes), embeds (`![[note]]` to pull a whole file inline), frontmatter properties, and block-level links (`[[note#^block-id]]`).

Where this actually shows up: a client rule that bit you can sit in a warning callout instead of a plain line. A winner note can embed the actual ad rather than linking away to it.

From [kepano/obsidian-skills](https://github.com/kepano/obsidian-skills) — Steph Ango, Obsidian's CEO. MIT.
