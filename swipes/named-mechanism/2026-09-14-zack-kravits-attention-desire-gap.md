# Swipe: Attention vs desire — matched proof → "the gap" → product bridge

Related: [[_organizing-swipes]] · [[2026-09-14-zack-kravits-message-isolator]]

**Source:** [Zack Kravits Instagram reel](https://www.instagram.com/p/DcJsaewAckk/)

**Seen running:** 2026-09-14. The post metadata showed 7,081 likes and 4,801 comments when captured. That is strong response evidence, not proof of paid-ad performance.

**Mechanism:** Start with a metric the avatar already wants (attention), split it from the business outcome they actually need (desire), then prove the distinction with two posts that reached roughly the same audience but produced radically different comment/download counts. Name the missing process **"the gap"**: symptoms → desired outcome → the gap between them → an asset/tool/offer that bridges it.

**Why it works:** The ad does not ask the viewer to abandon views. It agrees that attention matters, then makes attention feel incomplete. The paired-post comparison earns the teaching: roughly 500K views each, but 438 comments / ~200 downloads versus 31K comments / ~15K downloads. Only after that contrast lands does the named framework appear.

**The one thing to steal:** Use a matched pair with similar top-line performance but wildly different downstream value. Turn the difference into a missing variable, name it, teach it simply, and make the CTA demonstrate the mechanism instead of merely asking for a click.

**Structure:** avatar call-out + desired skill → agree with the market's current goal → expose the missing half → matched proof contrast → name the framework → discredit the default approach → teach a simple diagram → position product/resource as the bridge → restate the two-part payoff → comment-keyword CTA with a useful asset.
