# Swipe: zalo.kabche — "The AI-Powered $5K System" (old-way-vs-new-way + numbered system)

Related: [[_organizing-swipes]] [[2025-12-23-ai-agency-price-drop-urgency]]

**Seen running:** 2025-12-22, 2025-12-23 (two creative variants, same offer, back-to-back days)

**Mechanism:** Split-screen comparison — left side stacks the old way's pain in short, clipped labels ("3-Week Builds," "Price Wars," "Traditional Agency Hell," "Wasted Calls," "Ignored Proposals," "60-Hr Grinds," "Another $500 project"), right side is a clean numbered system: "1. Send AI Demo (3 min) → 2. Send Video Pitch (5 min) → 3. Deploy & Get Paid (75 min)." Closes on a result line: "10 Links = $50K Pipeline." The second variant (Dec 22) runs the same "trading time for money?" premise with a more chaotic collage execution.

**Why it works:** the old-way column isn't generic pain, it's *specific agency-owner pain* (ignored proposals, price wars, 60-hour grinds) — every label reads like something the prospect has actually lived. Stacking that against a 3-step, time-stamped system (3 min / 5 min / 75 min) makes the new way feel almost absurdly simple by comparison. The time-stamps are doing more work than the steps themselves — they're the proof the system is real and fast.

**The one thing to steal:** when you build an old-way/new-way split, don't write the old-way column as "problems" — write it as the exact phrases the prospect would use to describe their week. And if your new way has steps, time-stamp them. A number alone ("3 steps") is a claim; a number with a duration ("75 min") is a demo.
