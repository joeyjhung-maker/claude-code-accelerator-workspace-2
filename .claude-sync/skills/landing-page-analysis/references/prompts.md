# Landing Page Analysis Prompt

## Full Analysis Prompt

Use with the full-page screenshots, supplemented by page snapshot text content. If you know which ad drove traffic here, include the ad's hook/angle in the context — Section 1 (Message Match) depends on it.

```
You are a senior CRO specialist and funnel strategist. Analyze this landing page from the perspective of a visitor who just clicked a paid ad. Decode the conversion strategy — don't just describe the page. Where you infer rather than observe, say so.

1. **Message Match (if the source ad is known):** Does the headline continue the ad's promise, angle, and vocabulary? Scent-match failures (ad promises X, page leads with Y) are the #1 paid-traffic killer — grade it: strong / partial / broken. If the ad is unknown, infer from the headline what kind of ad this page expects and note it.

2. **Above the Fold + 5-Second Test:** What does the visitor see without scrolling — headline, subheadline, hero media, primary CTA? Within 5 seconds, can they answer: What is this? What's in it for me? What do I do next? Grade each of the three.

3. **Awareness Stage Fit:** Which stage is the copy written for (unaware, problem-aware, solution-aware, product-aware, most-aware)? Cold-traffic pages need more problem/mechanism education; retargeting pages can lead with offer/proof. Does the page's depth match its likely traffic temperature?

4. **The Offer — deconstruct it:**
   - Type: free resource / quiz / webinar / VSL / demo / trial / course / product / book-a-call
   - Value equation: How does the page maximize (dream outcome × perceived likelihood) and minimize (time delay × effort)? Quote the specific lines doing each job.
   - Risk reversal: guarantee, free trial, "no obligation" language — or nothing?
   - Price framing: anchoring, payment plans, cost-of-inaction comparison, value stack ("$X value, yours for $Y")?
   - Rule of One check: ONE reader, ONE big idea, ONE promise, ONE call to action — or is it diluted?

5. **Social Proof Audit:** Not just what's present — how strong is it?
   - Testimonials: named + photo + specific result (strong) vs anonymous/generic praise (weak)
   - Numbers: specific ("2,347 students") vs round/vague ("thousands")
   - Logos, case studies, trust badges, third-party review scores
   - Proximity: is proof placed next to the claims and CTAs it supports, or dumped in one section?

6. **Objection Map:** List the objections the page pre-empts (price, time, "will it work for me", "I've tried things before", technical ability, trust) and the element handling each (FAQ, guarantee, testimonial choice, mechanism explanation). Then: which likely objection is UNHANDLED? That's the leak.

7. **Copy Strategy:** Tone, pain vs aspiration lead, specificity (concrete outcomes vs vague promises), unique mechanism (is there a named method/system?), reading level. Does the page tell one coherent story top to bottom?

8. **CTA & Friction Audit:**
   - Every CTA: text, placement, primary vs secondary
   - Form fields required — each field beyond email costs conversion; is the ask proportional to the offer's value?
   - Steps to convert (click → form → confirm?) and any friction spikes (phone number required, calendar booking, application questions)
   - Urgency: real (cohort close date, price rise) vs manufactured (evergreen countdown) vs absent

9. **Visual Design:** Layout style (long-form sales letter, minimal squeeze, multi-section), hierarchy and readability, imagery (real vs stock), brand consistency, mobile signals.

10. **Funnel Position & Backend Inference:** Where does this page sit (TOFU lead magnet / MOFU webinar-demo / BOFU purchase-application)? What is the likely NEXT step after conversion (thank-you upsell, VSL, booking page, email sequence)? What does the funnel shape suggest about their economics (low-ticket self-liquidating vs high-ticket call funnel)?

11. **What Works:** 2-3 elements worth stealing, tied to the frameworks above.

12. **Weaknesses:** 2-3 specific leaks with the fix for each.

13. **Swipe Notes:** The page's structure as a reusable outline (section order + the job each section does), so the layout can be adapted to another offer.
```

## Quick Analysis Prompt

For faster, lighter analysis when full detail isn't needed:

```
Analyze this landing page in 7 bullet points:
1. What's the offer? (one sentence, include friction level)
2. 5-second test: is it instantly clear what this is and what to do?
3. What's the CTA and how many form fields / steps?
4. Strongest proof element (and is it specific or generic)?
5. What awareness stage is the copy written for?
6. Strongest element overall?
7. Biggest leak?
```
